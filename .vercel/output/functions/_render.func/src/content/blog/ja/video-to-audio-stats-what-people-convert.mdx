# 実際に変換されているもの：動画から音声への変換利用統計とインサイト

どの動画形式が最も多く変換されているのか、気になったことはありませんか？ ユーザーが処理するファイルのサイズはどれくらいなのでしょうか？ Dayrontから得られた匿名化されたデータ（**変換回数**のみを集計し、ファイルの内容は一切確認していません）を分析し、これらの興味深い傾向をお届けします。

> **プライバシーに関する注意：** すべてのデータは完全に匿名化されています。フォーマットとファイルサイズの範囲のみを集計しており、ファイル名や内容については一切調査していません。

## 最も多く変換されている動画フォーマット

過去1か月間の入力動画フォーマットの内訳は以下の通りです：

| フォーマット | 変換に占める割合 |
|--------|----------------------|
| MP4    | 64% |
| WebM   | 14% |
| MOV    | 10% |
| MKV    | 7% |
| AVI    | 4% |
| その他  | 1% |

<img src="https://images.unsplash.com/photo-1611162616475-46b635cb6868?w=800&q=80" alt="変換形式のシェアを示すグラフ" width="800" height="534" class="rounded-xl my-6" loading="lazy" />

MP4が圧倒的なシェアを占めています。スマートフォン、ドローン、そしてほとんどのカメラがMP4形式で録画することを考えれば、これは驚くことではありません。WebMはYouTubeからのリッピングやウェブからのダウンロードのおかげでシェアを伸ばしており、一方、MOVはiPhoneユーザーの間で依然として人気があります。

## 平均ファイルサイズ

入力ファイルをサイズ区分（MB単位）ごとに分類しました：

| サイズ範囲 | 割合 |
|------------------|------------|
| 0～10 MB | 28% |
| 10～50 MB | 41% |
| 50–200 MB | 22% |
| 200–500 MB | 7% |
| 500 MB以上 | 2% |

<img src="https://images.unsplash.com/photo-1558494949-ef010cbdcc31?w=800&q=80" alt="ファイルサイズの棒グラフ" width="800" height="450" class="rounded-xl my-6" loading="lazy" />

最適な範囲は **10～50 MB** です。これは通常、5分未満の短い動画に相当します。この範囲であれば、モバイル端末でも素早く変換でき、生成されるMP3ファイルは通常5 MB未満になります。

## 音声抽出を行う理由

ユーザーに（任意のアンケートを通じて）、なぜ動画を音声に変換するのかを尋ねました。主な理由は以下の通りです：

1. **音楽・サウンドトラックの保存** (38%)
2. **音声録音／講義の抽出** (27%)
3. **ストレージ容量の削減** (18%)
4. **プライバシー保護** – 映像コンテンツの削除 (12%)
5. **その他** (5%)

プライバシーに関する理由が注目されます。10%以上のユーザーが、動画自体は必要なく、誤って共有してしまうのを避けたいという理由で音声に変換していると具体的に挙げています。

## 地域別の分析

位置情報は追跡していませんが、言語設定から大まかな分布がわかります：

- 英語：45%
- スペイン語：18%
- ポルトガル語：12%
- ドイツ語：10%
- フランス語：8%
- 日本語：7%

これにより、翻訳作業やサーバー設置場所の優先順位付けに役立てています。

## ユーザーにとっての意味

- **MP4が主流**ですが、当社のツールはMOV、MKV、AVI、WebMも同様に処理可能です。
- **200 MB未満のファイルが一般的**であり、Dayrontでは数秒で処理します。
- **プライバシーは重要です** – ユーザーの多くは、機密性の高い動画の変換にローカル変換を選択しています。
