## Understanding Video Containers and Codecs

### What's the Difference?

**Container (format):** The "wrapper" that holds video, audio, and metadata. Examples: MP4, MOV, WebM, AVI, MKV.

**Codec:** The method used to compress video and audio. Examples: H.264, H.265, VP8, VP9, ProRes.

**Key insight:** The container and codec are different things. An MP4 file can contain H.264 or H.265 video. A MOV file can also contain H.264 or ProRes. When converting, you may need to change both the container and the codec.

### Format Deep Dive

| Format | Extension | Common Codecs | Best For |
|--------|-----------|---------------|----------|
| **MP4** | .mp4 | H.264, H.265 | Universal distribution, YouTube, social media |
| **MOV** | .mov | H.264, ProRes | Apple editing, professional workflows |
| **WebM** | .webm | VP8, VP9 | Web embedding, open source |
| **AVI** | .avi | Various | Legacy compatibility |
| **MKV** | .mkv | H.264, H.265 | Archiving, multiple tracks |

## Advanced Conversion Tips

### Tip 1: Convert Before Editing

If you're going to edit the video, convert to a format your editor handles well. Most editors prefer MP4 (H.264) or MOV (ProRes). Convert before importing to avoid issues.

### Tip 2: Preserve Original Quality

When possible, use settings that match or exceed the original quality. Converting from a low-quality source to high-quality settings won't improve quality – it just creates a larger file.

### Tip 3: Batch Convert When Possible
