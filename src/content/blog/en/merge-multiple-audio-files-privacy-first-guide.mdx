Before merging, ensure all files are in a compatible format and have consistent volume.

**Format check:** If files are in different formats, convert them all to MP3 or WAV using the **[Audio Converter](/tools/audio-converter)**.

**Clean check:** Remove silences and unwanted sections from each file using the **[Audio Cutter](/tools/audio-cutter)**.

### Step 2: Open the Audio Merger

Navigate to the **[Audio Merger](/tools/audio-merger)**.

### Step 3: Upload Your Files

Drag all your audio files into the upload area. **Your files stay on your device** – nothing is uploaded to a server.

### Step 4: Arrange the Order

Arrange files in the order they should play. The top file plays first, the bottom file plays last.

### Step 5: Merge

Click "Merge" and wait for processing. For typical audio files, processing takes seconds.

### Step 6: Clean Metadata

Toggle **"Clean File Privacy Before Download"** to remove:
- Author names

Download your merged file. It's ready for distribution.

## Common Merging Scenarios

### Scenario 1: Combining Interrupted Recordings

**The problem:** Your interview was interrupted three times (battery changes, phone calls). You have four separate recordings.

**The solution:**

1. **Clean each recording** – Use Audio Cutter to remove the interruption moments and any dead air.
2. **Match volumes** – Use Volume Booster to bring all recordings to similar levels.
3. **Merge** – Open Audio Merger, upload all four files in order, merge.
4. **Polish** – Apply light compression to the merged file for consistency.

**Result:** A seamless interview that sounds like it was recorded in one take.

### Scenario 2: Creating a Podcast Episode

**The problem:** You have separate intro, main content, and outro files.

**The solution:**

1. **Prepare each file** – Trim silence, compress, boost.
2. **Convert to same format** – Use Audio Converter to make all files MP3 at 128 kbps.
3. **Merge** – Arrange in order: intro → main → outro.
4. **Final polish** – Apply compression and boost if needed.

**Result:** A complete podcast episode ready for distribution.

### Scenario 3: Combining Voice Memos

**The problem:** You have 15 short voice memos that need to become one audio note.

**The solution:**

1. **Quick clean** – Remove obvious silence from each memo using Audio Cutter.
2. **Merge** – Upload all 15 files in chronological order, merge.
3. **Convert** – Output as MP3 for easy sharing.

**Result:** A single audio file containing all your notes.

### Scenario 4: Adding Music to Voice

**The problem:** You want background music under your voiceover.

**The solution:**

1. **Prepare voice** – Compress and boost to -16 LUFS.
2. **Prepare music** – Set volume 10–14 dB below voice.
3. **Merge** – Music first, then voice (voice plays over music).
4. **Polish** – Final compression to glue the mix.

**Result:** A professional voice + music mix.

## Advanced Merging Tips

### Tip 1: Normalize Before Merging

If files have different volumes, normalize them first:

1. Process each file with Volume Booster to reach similar levels.
2. Then merge.

This prevents jarring volume jumps between sections.

### Tip 2: Add Silence Between Sections

A brief pause (0.5–1 second) between sections creates natural transitions:

1. Create a short silent audio file (or use a quiet room tone).
2. Insert it between files in the merger.
3. This creates a natural break instead of abrupt transitions.

### Tip 3: Convert Everything to the Same Format

Mixing formats (WAV + MP3 + M4A) can cause issues. Convert all files to the same format and sample rate before merging.

**Recommended:** MP3 at 44.1 kHz for voice, 128 kbps.

### Tip 4: Keep Originals

Always keep your original files. If the merge doesn't sound right, you can go back and adjust individual elements.

### Tip 5: Apply Light Compression After Merging

A light compression pass (level 2–3) after merging helps "glue" the different files together, creating a more cohesive sound.

## Privacy: Why Local Merging Matters

When you use cloud-based audio mergers, all your files are uploaded to a third-party server. This creates risks:

**1. Multiple File Exposure**
Not just one file – all your audio files are accessible to the service provider.

**2. Content Correlation**
A cloud service can see all your files together, potentially revealing patterns about your work or sources.

**3. Metadata Leakage**
Each file contains metadata. Batch uploading means multiple metadata sets exposed.

**4. Data Retention**
Many services keep copies of your files indefinitely.
